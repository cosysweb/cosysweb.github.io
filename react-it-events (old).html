Categories

Monitor Name Frequency Brief Explanation
AV Disabled Daily If your Antiviruse software is supported, the Antivirus software detected but is showing disabled
AV Out Of Date Daily If your Antivirus software id supported, the Antivirus software is out of date by more than 21 days
AV Software Missing Daily No Functional Antivirus software detected on system
Bad Process Detected Daily Bad system processes are normally related to spyware and Malware
Firewall Disabled Daily The computer's local firewall software is disabled. This could be caused by a virus or trojan.
Hardware Changes Detected Every 2 Days Changes in system Hardware indicate someone has been attaching devices to the computer or changing the configuration
TCP Suspicious Ports Daily A known bad port on the system has been accessed by a process. This is usually malware, spyware or a virus.
Updates Failed Automatic Every 3 Days Windows Update has failed to install a required patch
Updates Adobe / Java Out of Date Every 30 Days Your system is missing a Critical Security updates for Adobe and Java related software and is very vulnerable.
Updates OS Missing Service Pack Every 7 Days Your system is missing a Critical Windows OS Service Pack installation and is vulnerable.
Updates Office Missing Service Pack Every 30 Days Your system is missing a Critical MS Office Service Pack installation and is vulnerable.
Updates Out of Date Daily Your system is missing Windows Updates and needs to be updated for security, stability and reliability
Drive Fragmentation Daily Hard Drive fragmentation greater than 15% adversely effects system performance
Drive Free Space Daily Hard Drive free space less than 10% adversely effects system performance
Time Sync Errors Every 7 Days Errors reported by the Windows Time Sync process that is used to keep computer time correct
TCP Duplicate IP in Network Every 3 Days A duplicate address was used on the network which causes conflicts
Data Backup Failed Daily If your data backup program is supported, reports that your Data backup job failed to complete.
Internet Down 24x7 The Internet at your location has offilne for over 20 minutes.
Server Down 24x7 The monitored Server has been offline for over 30 minutes.
Server Service Stopped Hourly Software or Server function has stopped working on the Server.
Windows Startup Overloaded Daily Windows starts up with more than 18 programs running in the background which leads to slow performance
Excessive Alerts Detected Every 5 Days Windows Events that exceeded 25 occurrence in a 5 minute period
Performance 90% Plus Avg CPU Daily The system CPU has exceeded 90% of it's total capacity. System is over capacity or less activities need to be done at once
Performance Low Memory Daily Less than 15% of the total memory was available indicating the system needs more memory or less activities need to be done at once
Drive NTFS Errors Every 2 Days Errors recorded that indicate a hard drive has issues and needs to be checked prior to failure
Drive SMART Failures Daily Physical failure of a hard drive. Hard drive needs to be replaced.
Shutdown Unexpected Daily Either the computer crashed (Blue Screened) or the computer was improperly shutdown. This can corrupt your data
Environment Critical Daily Windows System monitoring that indicates a critical issue exists
Environment Reoccurring Critical Every 3 Days Continued Window System issue that has occurred more than 85 times on the system within the last 3 days
